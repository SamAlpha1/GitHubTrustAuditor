# Community Conduct

GitHub Trust Auditor welcomes technical discussion, bug reports, security research, and contributions that improve defensive analysis.

Please keep participation respectful, evidence-based, and focused on the code or observable technical behavior. Do not use the project to harass, threaten, impersonate, or make unsupported accusations about people.

When reporting suspicious behavior:

- describe the observable code pattern,
- include reproducible evidence where safe,
- redact real secrets and personal data,
- distinguish technical risk indicators from claims about a person's intent or identity.

Do not publish live private keys, seed phrases, access tokens, passwords, or other credentials in issues, pull requests, screenshots, or test fixtures.
